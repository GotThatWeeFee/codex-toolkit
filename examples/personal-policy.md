# Optional personal policy example

Review and adapt this text manually in your own instructions. Installation never copies it into AGENTS.md. These are choices, not shared defaults.

- If I request model recommendations, offer two supported model/effort pairs with task-specific reasons, using current runtime capabilities. A recommendation does not switch the model. Once I select, proceed within the authorized scope without another kickoff prompt.
- Preserve my existing changes. Do not stage, commit or push unless I explicitly authorize the exact action.
- Add or run tests only when I explicitly request them. Report performed static checks and unrun tests separately.
- Follow my project instructions for Jira issue hierarchy and estimates. Automatic worklogs, comments and status transitions require my defined standing authorization and a clearly associated issue. Record measured time only, avoid duplicate writes and verify persistence.

Keep project business rules, architecture, examples, test data and service mappings in the owning project. Keep account permissions, credentials, trust state and hooks outside this repository.
